# دقيقة وعي — الإصدار 2

تطبيق React عربي للتعلّم عبر اللعب: استكشاف حر، جولة يومية، وتقدّم محلي. بلا Backend أو حسابات أو خدمات مدفوعة داخل التطبيق.

## التشغيل

يلزم Node.js 22.12 أو أحدث. افتح الطرفية داخل مجلد المشروع:

```sh
npm ci
npm run dev
```

افتح العنوان الظاهر، عادة http://127.0.0.1:5173 . أوقف التشغيل بـCtrl+C.

```sh
npm test
npm run build
npm run preview
```

`build` ينتج ملفات الموقع في `dist/`، و`preview` يعرضها محليًا. هذه الأوامر لا تنشر المشروع. يحتاج التثبيت الأول اتصالًا بالإنترنت؛ اللعب بعد ذلك لا يعتمد على خدمات خارجية. افتح ملفات البناء بخادم المعاينة، وليس بالنقر المزدوج على index.html.

## التجربة

44 تحديًا مكتوبًا، في 10 طرق لعب:

| التجربة | ما يفعله اللاعب |
|---|---|
| موقف يتفرّع | يختار ردًا، يرى استجابة محتملة، ثم يختار متابعة الحوار |
| اكشف الخدعة | يعلّم العبارات التي تستحق التحقق، ثم يراجع الأدلة |
| رتّب التصرّف | يحرّك الخطوات بأزرار لأعلى ولأسفل |
| ابنِ ردّك | يبني رسالة من أجزاء ويستبعد صيغًا غير مناسبة |
| بدّل الزاوية | يكشف منظورًا إضافيًا قبل اختيار سؤال توضيحي |
| فرّق بينهما | يصنّف عبارات بين فئتين |
| اختبر حدسك | يقدّر قيمة على مقياس ويقارنها بالحساب |
| صل الفكرة | يربط المفهوم بالموقف مع إمكانية تغيير الربط |
| ماذا سيحدث؟ | يتوقع نتيجة في موقف علمي مصوّر |
| فرز سريع | يتخذ ثلاثة قرارات متتابعة ضمن سؤال واضح |

6 تحديات للحوار و6 لفحص الخدعة، و4 لكل نوع آخر. دفتر الأفكار يحتفظ بالمحتوى السابق: 30 فكرة ومفضلة محلية وروابط مصادر.

## التقدّم والجولة اليومية

- كل أنواع اللعب مفتوحة من البداية؛ تبدأ بتحديات المستوى الأول.
- بعد إكمال تجربتين مختلفتين داخل نوع لعب يفتح مستواه الثاني؛ وبعد ثلاث يفتح الثالث حيث يتوفر محتوى له.
- الاختيار الافتراضي يعطي أولوية للمحتوى الذي لم تجرّبه، ضمن المستوى المتاح.
- الإكمال الأول يمنح 20–30 نقطة بحسب نتيجة الجولة. الخطأ لا يسحب نقاطًا؛ التلميح مجاني.
- التحدي المكتمل يمكن مراجعته وإعادته دون مضاعفة النقاط. التقييم المحفوظ هو أول إكمال، وليس أفضل محاولة لاحقة.
- كل 150 نقطة يرتفع المستوى العام. التقدّم داخل كل نوع يُقاس بعدد تحدياته المختلفة المكتملة.
- الجولة اليومية تجمع ثلاثة أنواع مختلفة؛ اكتمالها يمنح 30 نقطة إضافية مرة واحدة لذلك اليوم.
- اللعب الحر لا يكمل محطات الجولة تلقائيًا؛ ادخل المحطة من شاشة الجولة لتحتسب فيها.
- الأيام المتتالية تتعلق بأيام الإكمال حسب تاريخ جهازك. لا تحذف انقطاع السلسلة نقاطك أو المحتوى المفتوح.
- المؤقت اختياري، يتوقف عند إخفاء الصفحة، وانتهاؤه لا يغلق اللعبة أو ينقص النقاط.

هذه مكتبة معدة مسبقًا، وليست محتوى مولدًا بالذكاء الاصطناعي أو تحديثات من الإنترنت. التشكيلة اليومية تتغير، لكن المحتوى نفسه محدود ويمكن مراجعته. إضافة دفعات جديدة تتم بتعديل ملف المحتوى وإصدار تحديث. لا نعد بتوليد محتوى جديد لا نهائيًا.

## ملفات المشروع

```text
src/
  App.jsx          تنقل التطبيق وشاشات الاستكشاف والجولة والرحلة والدفتر
  Player.jsx       إدارة جلسة اللعب، المؤقّت، التلميح، والنتيجة
  Games.jsx        التفاعلات العشرة
  gameData.js      تعريف الأنواع و44 تحديًا ومصادرها
  gameEngine.js    النقاط والدورات والاختيار والتدرج وتنظيف الحفظ
  Art.jsx          الرسوم الأصلية ورمز العلامة
  cards.js         الأفكار الثلاثون السابقة
  domain.js        البحث وحفظ الدفتر
  main.jsx         تشغيل React والخط المحلي
  styles.css       نظام الألوان والتخطيط المتجاوب
public/licenses/   إشعارات وتراخيص المكتبات والخط
tests/            اختبارات البيانات والحفظ والتقدم والتقييم
```

## إضافة محتوى

أضف كائنًا إلى `activities` في `src/gameData.js` مطابقًا لحقول نوعه. أبقِ `id` فريدًا وثابتًا عند تصحيح نشاط موجود، وحدّث مصدره عند الحاجة. `difficulty` من 1 إلى 3. اترك تحديين على الأقل في المستوى الأول حتى يمكن فتح المستوى التالي. أعداد التحديات في البطاقات تُحسب تلقائيًا؛ العدد المكتوب في صفحة الإعدادات يحتاج تحديثًا يدويًا عند إضافة دفعة.

الردود في الحوارات احتمالات تأليفية للتدريب وليست تنبؤات عن الأشخاص أو تشخيصًا. بعض المواقف تحتمل أكثر من رد مناسب؛ التفسير يشرح المفاضلة. الترتيب وصياغة الرسالة نماذج مقترحة، وليسا قوانين لكل موقف. الأمثلة الحسابية أصلية وخطواتها موضحة. تظهر المراجع بعد الإكمال، وقد تكون بالإنجليزية.

## الحركة والأداء

- Motion 14.5.0 من `motion/react` للتفاعل، وإعادة الترتيب، وانتقال حالات اللعب والنتيجة.
- GSAP 3.15.0 وScrollTrigger لحركة الرسم أثناء التمرير على الكمبيوتر؛ تحميلهما مؤجل، ولا يعمل الأثر مع تفضيل تقليل الحركة.
- أدوات الحركة لا تتحكم بالعنصر نفسه في الوقت نفسه. لا مكتبات ثلاثية الأبعاد أو أصول تتطلب خدمات خارجية.
- شاشة اللعب تُحمّل عند فتحها. الخط والأيقونات محلية. لا تحميل تلقائي للمصادر الخارجية.

## الحفظ والخصوصية

`daqiqah:play:v2` للتقدّم الجديد، و`daqiqah:v1` لدفتر الأفكار والمفضلة السابقة. الحفظ مرتبط بالمتصفح والعنوان والجهاز. حذف بيانات الموقع أو استخدام الوضع الخاص قد يفقد التقدم. عند منع التخزين يظهر تنبيه ويستمر اللعب في الذاكرة. لا مزامنة بين الأجهزة أو النوافذ. يُحفظ الإكمال؛ الخروج من جولة غير مكتملة أو تحديثها يعيد بدايتها.

راجع `ENVIRONMENT.md` لما ثُبّت فعليًا وحدود الأدوات، و`TESTING.md` للاختبارات الفعلية وما لم يُختبر. لم يُنشر المشروع ولم يُربط بـGitHub. لا تحتوي الحزمة المضغوطة node_modules؛ يثبتها npm ci.
